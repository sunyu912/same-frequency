# 同频 Same Frequency

Bilingual (中文 / English) landing page for **Same Frequency**, a student research project on intergenerational communication, communication differences and neurodiversity.

- `index.html` — the whole site (inline CSS + JS, no build step)
- `assets/` — photography

Language toggle is in the top-right; the choice is remembered per browser.
Sign-ups are saved in the visitor’s browser (localStorage key `sf-signups`). Open `/#signups` in the same browser to view them, download a CSV, or clear them.
